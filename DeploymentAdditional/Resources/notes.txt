The current version of the addin is 1.2.3.1 and it is based on the TEST version 5.1.3.. Visit the official TEST website at https://www.epa.gov/comptox-tools/toxicity-estimation-software-tool-test for more info about TEST and its models.

The addin has been developed and tested for the QSAR Toolbox version 4.9. The addin makes available the following QSAR models from TEST:
Water solubility model (TEST)
Vapour pressure model (TEST)
Melting point model (TEST)
Mutagenicity (Ames test) model (TEST)
Developmental toxicity model (TEST)
Acute toxicity (LD50) model (TEST)
BCF model (TEST)
96 h fathead minnow acute toxicity (LC50) model (TEST)
Daphnia Magna LC50 48h (TEST)
